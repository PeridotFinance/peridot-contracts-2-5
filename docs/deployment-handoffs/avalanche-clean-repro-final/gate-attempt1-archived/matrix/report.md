## Funded in-kind fallback with finite funding (class `fallback*`)

One allowlisted funder, funded ONCE per scenario (30,000 USDC and 3,500 WAVAX, approvals limited to the budget), no replenishment between attempts, cumulative seized inventory. At each stressed step the NORMAL route is attempted first; positions it leaves liquidatable go to the funded route at the same state. `fb-nofloor-*` runs the funder with no break-even floor (it absorbs any shortfall); all others use the floor (`minSeizeValueBps` = 10,000). `redeemable now` = min(inventory, market cash) per market (an upper bound: other holders compete for the same cash). Funder P&L is seized value minus repaid value at the oracle price at each attempt (not realised). The route draws no insurance; `insurance used` is the NORMAL route's draw. The USDC-depeg slice applies the depeg AFTER the positions are opened.
