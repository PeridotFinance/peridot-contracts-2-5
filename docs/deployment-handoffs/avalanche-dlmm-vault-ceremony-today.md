# DLMM vault ceremony TODAY: what the operator types and signs (one page)

Run everything from `contracts/vault-dlmm/`. `OPERATOR` = only the operator, with a key or the Ledger in hand. No mark = read-only, anyone. The RPC endpoint is in the environment (`ETH_RPC_URL` for `cast`, `AVALANCHE_MAINNET_RPC_URL` for `forge`), never an argument. Details and the reasoning: `avalanche-dlmm-vault-ceremony.md`. Status of the tools: the 3-call flow was rehearsed on a fork; the 4-call split below was checked offline only and its fork re-run is pending (see the rehearsal report). **At every step that shows `simulation passed` / `SIMULATION ... true`, read the decoded call and the nonce it prints; if the simulation fails or the decoded call is not what is written here, STOP.**

**Before anything:** (a) W5 has reported the keeper wallet: `export KEEPER_WALLET=0x...` (the vault's rebalancer is set at deploy: the deploy cannot happen before this address exists) `[KEEPER_WALLET = placeholder until W5 reports]`; (b) risk register accepted; (c) the operator has confirmed the split: **1 USDC to `0xdEaD`, 199 USDC of shares to the Ledger, total 200 = the cap, no outside deposit fits**; (d) the Ledger holds at least 200 USDC and about 1.5 AVAX; (e) `forge build --skip test` done at the reviewed commit.
